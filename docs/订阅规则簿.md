# 订阅规则簿

本簿记录消费方订阅清单与放行可见集合的正确性口径。**本簿一经写入禁止改口**：
口径同步落库于 `subscription_meta.semantics`，运行时每次订阅变更与放行裁决前校验，
偏离即拒绝并记录。本簿与代码常量 `SEMANTICS`（`backend/app.py`）必须逐字一致。

## 互斥口径择一（已选定，两边不得混用）

- **甲（已选定）**：订阅变更与放行可见集同一库事务内提交，失败时整笔回滚。
- 乙（未选用）：订阅先写草稿，确认后原子切换正式订阅，切换前仍按旧清单裁决放行。

## 甲口径下的同步边界

1. **同事务提交**：订阅变更（订阅/退订）与放行可见集版本（`subscription_meta.version`）
   在同一 SQLite 事务（`BEGIN IMMEDIATE`）内提交；任一步失败整笔回滚，不留半截状态。
2. **放行同事务**：放行裁决、订阅状态检查、放行流水（记 `sub_version`）、消费水位
   （记 `release_id`）在同一事务内读写，同成同败。
3. **两条禁止**：清单已删（已退订）消费方禁止继续收到水位推送；未订阅消费方禁止偷接
   放行。违反即拒绝，放行流水记「拒绝」，备注与订阅审计同记「订阅口径偏了」。
4. **争用串行**：两名订阅值班同时改落，数据库写锁串行 + 口径版本乐观校验；后手提交
   收到「订阅争用」并落审计，禁止默成。
5. **四画面对读**：切片列表旁注、订阅目录、放行详情、水位画面同源同口径版本，
   必须能互相核对。
6. **本机文件库**：继续沿用 SQLite 文件库 `data/app.db`，不挂外置库。
